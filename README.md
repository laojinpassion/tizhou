# 题舟 TiZhou · 通用刷题引擎

> 题海无涯，题舟渡你上岸。

一个**单文件、免下载、免注册**的通用刷题引擎。整个应用就是一个 HTML 文件：电脑双击打开、手机浏览器打开都行，进度存在本机，不需要联网、没有广告、没有账号体系。

**在线使用**：<https://laojinpassion.github.io/tizhou/>

## 已内置数据包

| 考试 | 题库规模 | 模考 |
|---|---|---|
| 🚦 机动车驾驶考试（科目一） | 117 题（法规/标志标线/安全驾驶/记分处罚/事故急救 5 章） | 100 题 · 45 分钟 · 90 分及格 |
| 🎓 中级经济师（工商管理）2026 | 经济基础知识 382 题 · 工商管理实务 165 题（含 8 个案例分析大题），48 章全覆盖 | 经济基础卷 105 题 · 工商卷 100 题（含 20 案例小题），105 分钟，按真题规则评分（满分 140 / 84 及格） |

更多类目（初级会计、教资、一建二建、软考、执业药师、公务员等）按数据包节奏滚动上线。

## 功能

- **两种揭晓模式**：批量揭晓（5 题一组做完统一判分，检索练习效果更好）/ 即时揭晓（做一题看一题）
- **错题本**：自动收集，重做全对自动移出，记录日期
- **全真模考**：按数据包配置的题型结构组卷、计时、到时自动交卷、断点续考、成绩历史
- **理解配图**：27 张内嵌 SVG 示意图（成本曲线、波士顿矩阵、供求图等），自动挂接到相关题目
- **章节统计**：每章进度与正确率、总正确率、考试倒计时
- 手机/电脑自适应，进度存 localStorage（同设备同浏览器）

## 给其他考试加一个数据包

引擎与内容分离：**加一门考试 = 加一个数据包，引擎零改动**。

1. 新建 `src/exam.<你的考试id>.json`：

```json
{
  "id": "mycert2026",
  "name": "XX资格证书",
  "icon": "📜",
  "dateLabel": "2026年X月X日 · 考试",
  "examDate": "2026-06-01T09:00:00+08:00",
  "totalScore": 100,
  "passScore": 60,
  "notice": "考试说明，显示在设置页",
  "subjects": [
    { "key": "xx1", "name": "科目一名称", "short": "科目一", "tag": "基础", "icon": "📘" }
  ],
  "mock": {
    "xx1": { "single": 50, "multi": 20, "case": 0, "total": 70, "dur": 90 }
  }
}
```

2. 新建 `src/bank_xx1_1.json`，按下面格式写题（`key` 与数据包里的科目 key 对应）：

```json
[{
  "s": "xx1", "p": "第一章", "c": 1, "cn": "章名",
  "t": "single",  // single=单选（4选项1答案） / multi=多选（5选项，答案≥2）
  "q": "题干", "o": ["A", "B", "C", "D"], "a": [0],
  "e": "解析（为什么对、为什么错、记忆钩子）",
  "k": "考点标签",
  "bg": "可选：案例分析背景材料（含 bg 的题归入案例分析，模考按 case 数随机抽取）"
}]
```

3. `node build.mjs` → 生成 `index.html`（Pages 用）与本地版 HTML。构建脚本会自动校验选项数、答案索引、题型、重复题干。

配图（可选）：27 张 SVG 在 `src/figs.js`，在 `src/fig_map.json` 里加一行"题干关键词 → 图名"即可自动挂图。

## 本地开发

```bash
node build.mjs      # 构建
node serve.mjs 8046 # 本地预览 http://127.0.0.1:8046
```
