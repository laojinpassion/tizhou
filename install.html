方式一 · 安卓手机直接安装 推荐

这是一个真正的安卓 App 安装包（APK）。装好后桌面有「题舟」图标，全屏打开、完全离线，不需要应用商店，也不需要注册任何账号。

下载安卓版 APK 不安装，先用网页版
版本 1.2.1大小 4.5 MB系统 Android 7.0 及以上权限 仅联网（不使用）

安装步骤

  1. 用手机系统浏览器（或 Chrome / Edge / 夸克）打开本页；
  2. 点上面的「下载安卓版 APK」，等下载完成；
  3. 点通知栏或文件管理器里的安装包，弹出提示时选择「允许安装未知应用」（只需一次）；
  4. 点「安装」→「打开」，桌面出现「题舟」图标，完成。
注意：微信、QQ、钉钉的内置浏览器不能直接安装 APK（会提示「不支持打开」）。请点右上角「…」选择「在浏览器打开」，或把链接复制到系统浏览器。
安装时安卓会提示「此应用来自未知来源」「应用未经检测」——这是所有不上架商店的应用都会收到的统一提示，不是文件损坏。题舟不含广告、不收集信息、不做任何联网请求，可放心安装。

方式二 · 添加到主屏幕（不装 APK）

不想装安装包时，可以把网页版添加到桌面，效果接近 App：有图标、全屏打开、首次访问后离线可用。

Android（Chrome / Edge / 夸克）

  1. 用浏览器打开 题舟网页版；
  2. 点右上角菜单 →「添加到主屏幕」或「安装应用」；
  3. 桌面出现「题舟」图标，点开即全屏使用。

iPhone / iPad（Safari）

  1. 用 Safari 打开题舟网页版（微信内置浏览器不支持）；
  2. 点底部「分享」按钮 →「添加到主屏幕」；
  3. 确认名称后，桌面出现图标。
若上面的按钮出现，直接点它即可；未出现时按菜单操作，效果相同。

方式三 · 单文件离线版 发给别人最方便

整个应用就是一个 HTML 文件（约 2.1 MB），含全部 2653 道题。下载后存到手机，用浏览器打开即可刷题，不需要网络、不需要安装、不需要任何账号。

方式四 · 直接把链接发出去

  • 发链接：把 https://laojinpassion.github.io/tizhou/ 发给对方，手机浏览器打开即用，零安装。
  • 发链接（安装页）：把本页地址发过去，对方可自行选 APK 或网页版。
  • 搜网址：搜索引擎收录需要时间，直接发链接比「搜名字」更快更可靠。
