把题舟装到手机

免注册 · 免应用商店 · 免登录 · 无广告 · 25 场考试 / 2653 道题

方式一 · 添加到主屏幕 推荐

像普通 App 一样有图标、全屏打开，首次访问后支持离线。不需要任何账号，也不需要应用商店。

先打开题舟

Android（Chrome / Edge / 夸克等）

  1. 用浏览器打开 题舟网页版；
  2. 点右上角菜单 → 「添加到主屏幕」或「安装应用」；
  3. 桌面出现「题舟」图标，点开即全屏使用。

iPhone / iPad（Safari）

  1. 用 Safari 打开题舟网页版（微信内置浏览器不支持添加）；
  2. 点底部「分享」按钮 → 选择「添加到主屏幕」；
  3. 确认名称后，桌面出现图标。
如果上面的「一键安装」按钮出现，直接点它即可；若未出现，按上述菜单操作，效果相同。

方式二 · 下载单文件离线版 完全离线

整个应用就是一个 HTML 文件（约 2.1 MB），含全部 2653 道题。下载后存到手机，用浏览器打开即可刷题，不需要网络、不需要安装、不需要任何账号。

下载离线版 HTML 先看考试目录

适合：发给别人、存网盘、无网环境、不想装任何东西。注意：离线版是独立文件，之后题库更新需要重新下载；不同文件的做题进度互不相通。

方式三 · 直接发文件 / 发链接 最省事

  • 发链接：把 https://laojinpassion.github.io/tizhou/ 发给对方，手机浏览器打开即用，零安装。
  • 发文件：把下载的离线版 HTML 通过微信/网盘发给对方，对方用手机浏览器打开即可，零安装。
  • 搜网址：搜索引擎收录需要时间；直接发链接或扫二维码比「搜名字」更快、更可靠。
三者的共同点：都不需要注册开发者账号、不需要软著、不需要应用商店审核。需要那些手续的只有「上架应用商店」这一条路。

使用前须知

  • 题目为依据公开考试大纲与通用教材生成的模拟题，非官方真题，以当年官方教材为准。
  • 做题进度只保存在当前浏览器 / 当前文件，清缓存、换设备或换文件会丢失。
  • 不收集、不上传任何个人信息；无账号、无广告、无付费。
  • 发现答案有误，可到 GitHub 提交纠错。
