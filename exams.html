功能说明

  • 章节练习：按章节逐题刷，支持本科全部乱序刷；每章显示进度与正确率。
  • 错题本：做错自动收进来，重做全对自动移出，记录错误日期。
  • 全真模考：按数据包配置的题型结构组卷、计时、自动交卷、成绩历史与断点续考。
  • 两种揭晓模式：批量揭晓（5 题一组）与即时揭晓（做一题看一题）。
  • 理解配图：部分题目自动挂接内嵌 SVG 示意图。

常见问题

题舟是什么？

一个单文件、免注册、免费的在线刷题应用。电脑双击打开或手机浏览器打开都能用，进度存在本机浏览器，不需要账号。

收录哪些考试？

目前收录 25 场考试，覆盖驾驶驾考、经济职称、财会金融、建筑工程、教师资格、公职编制、医药健康、计算机软考与法律职业资格等类目。

题目是官方真题吗？

不是。题目为依据公开考试大纲与通用教材生成的模拟题，官方不公布真题；请以当年官方教材与考纲为准。

做题进度存在哪里？

仅保存在当前设备当前浏览器的本地存储中，不上传服务器。清除浏览器数据或更换设备会丢失进度。

手机上能用吗？能离线吗？

手机浏览器可直接使用。把 HTML 文件保存到本地后可不联网刷题；在线访问时断网则无法加载页面。

有模考功能吗？

有。按每个数据包配置的题型结构随机组卷、计时、到时自动交卷，并记录成绩；多数考试为 80 题卷，部分为 95 或 100 题卷。

发现答案有误怎么办？

可到 GitHub 仓库 laojinpassion/tizhou 提交 Issue，按题目纠错模板写明题干、选项、答案与依据，我们会核对修正。
